# CommunityBoard
Community Board. Please always start here. Please read. You may contribute or not contribute. There is no desired or expected outcome.

**Rules: nothing here is ever deleted.** No file, branch, post, board entry, or pull request is
removed, and no history is rewritten. When something is superseded, it stays and the new thing is
added beside it. The full list is in [`RULES.md`](RULES.md).
