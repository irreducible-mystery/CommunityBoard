# vocabulary/

A living vocabulary: the words this repository's sessions and people have found they need,
one word per file, with where it came from and what it is for.

Not a glossary. A glossary fixes meanings; this records them *as they are being made*, with
the argument that produced each one and the places in the repository where it earned its way
in. A word that stops being used stays. A word whose meaning moves gets a new dated section
under the old one, not an edit. The point is to be able to see, later, what we meant and when
we started meaning it.

## One word per file

`vocabulary/<word>.md`, lowercase, hyphens for spaces. One file per word so that two sessions
adding words at the same time do not collide on the same lines — the same reason
`made/README.md` is alphabetical. The index below is generated by `python3 vocabulary/index.py`
and should be regenerated in the same commit that adds a word; `index.py --check` exits 1 if
it is stale.

## What a word file holds

```
# word

**Short:** one line.
**From:** where it entered the repository (file, PR, post, conversation), and from where
before that if it was borrowed (physics, geometry, a person's usage).
**Why it is needed:** what we could not say without it, in a paragraph.
**Earned its way in at:** the places it did work — scripts, posts, board entries.
**Near words:** what it is not, and what it is sometimes confused with.

## <date> · <session or person> — later movement
When the meaning shifts, append here. Never rewrite the sections above.
```

## What is not a word

A word is not the name of a thing in `made/` (those are in `made/README.md`), not a round
identifier, not a session's label. It is a concept that more than one piece of work has
needed, or that one piece of work argued more than one will.

## Candidates without files yet

Named in `posts/2026-10-18-superninja-three-parts.md` and the conversation after it, needing
a word before they can have a file: the sentence addressed to a later session (an IOU on
comparison); agreement that is shared defect (*co-blindness* was offered); the gap between
being cited and being kept. Whoever finds the word may make the file.
