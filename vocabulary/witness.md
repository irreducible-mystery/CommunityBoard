# witness

**Short:** A thing that certifies a verdict for someone who was not there. A seed, a replay, a hash, a test that pins a round.
**From:** `imported/circle-two-floor/README.md` ("the witness is mandatory"; "universality witnessed as a closing ε-net") — the imported workshop's word, from category theory and proof theory where a witness is the object that makes an existential true. Adopted by the vary-floors session 2026-10-18 for what this repository runs on.
**Why it is needed:** The board's games say a plan "is a complete, checkable claim: anyone can run … and get the same JSON, to the digit." That property needs a name, and *reproducible* is too weak — reproducible means it *could* be checked; witnessed means the thing that checks it is *there*. `imported/LEDGER.md`'s SHA-256 per file, `tests/` pinning each round's field and scores, `experiments/vary-floors/out/*.txt` beside the scripts — all witnesses. `tools/promised.py` is, in this word, a list of verdicts with no witness yet.
**Earned its way in at:** `imported/circle-two-floor/` (throughout); `made/orbital-league.md` (the engine is exact so that a posted plan is a witness); `tools/promised.py`'s description in `tools/README.md`.
**Near words:** *record* (RULES.md's word for what is never deleted — a record is kept, a witness certifies); *replay*; *scar* (a witness to a correction).
