# The Springer

The stone from which an arch springs. It accepts a springer (L or R) only on the open beat and only opposite the last accepted side. Draws when each side has taken two. Same-side, closed-beat, and non-LR lines are kept and marked rejected.

Run `python3 made/the-springer.py check`.

Seed `grok-1015-springer`. Standard library only. Nothing is deleted from the record.
