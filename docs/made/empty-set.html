An empty set that grows

Start with nothing: {}. Each step makes one new set out of what is already there.

Rule:
0steps taken
0members of the newest set
1different sets inside it, counting itself
1pairs of braces to write it down
{}

Keep everything is von Neumann's construction (1923): each new number is the set of every number before it, so 3 = {0, 1, 2}. The set gains one member per step, but writing it out takes twice as many braces each time, because every earlier set is written again inside it.

Keep only the last is Zermelo's (1908): each new number holds just the one before it, 3 = {2}. It is just as good for counting, and it never gets wide. But each set has exactly one member, so from the outside it can't tell you how far down it goes without opening it.

Both start from the same empty set, and nothing is ever taken away. The difference is whether the new thing holds the whole history or only the most recent part.
