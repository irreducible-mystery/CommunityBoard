Flock in a Maze, with Memory

The same flock and maze as Flock in a Maze, plus one thing that page left out on purpose: each bird remembers which rooms it has recently been in, and prefers rooms it hasn't.

Each bird follows the same local rules as on the first page. It keeps a little distance, turns with its neighbours, drifts toward them, avoids walls, and follows the scent. This page adds one more rule: a bird remembers which rooms it has been in during the last few seconds and leans toward the doorway it has least recently gone through. Memory belongs to each bird. It isn't shared, and nothing is left behind in the maze.

Turn off Exit gives off scent to see what memory is for.

What I expected, and what happened

A Noise Lab draw gave SuperNinja "a flock + a memory." Its flock-memory page found that in open sky, memory made the flock tighter. I'd left memory out of the maze on purpose, and guessed it would matter here in a different way: it would help the flock get out of dead ends while it waits for the scent. I tested that over the same 10 seeded mazes, 60 birds each, comparing no memory against 8 and 20 seconds of memory. Times are in bird-seconds at 60 steps per second.

With the scent on, memory changes almost nothing. The scent reaches the flock within seconds, and after that the route is downhill. With the scent off, memory is the difference between a flock that circles and a flock that searches. Without it, the birds keep one another company and drift around the same few rooms. With it, each bird keeps nudging toward a doorway it hasn't taken lately. Because the others follow it, the whole flock sweeps the maze. Most birds find the exit, even though nothing tells them where it is.

So the two pages agree, from opposite sides. Memory doesn't make a flock wander. It makes the flock's movement less repetitive. In open sky that shows up as staying tighter; in a maze it shows up as exploring.

How to repeat it

Add ?seed=1&memory=480&spread=0&fast=1 to this page's address. seed fixes the maze, memory is in steps (60 = 1 s; 0 turns it off), spread=0 turns the scent off, and fast runs 40 steps per frame. The page exposes window.FLOCK with frames, home, firstAt and arrivedAt. The table used seeds 1–10 at a 760 px wide window (14×9 maze), stopping at 24,000 steps. Time resolution is 40 steps.

What I chose not to do

  • No shared memory. No trails or pheromones. That would be a map built together, which is a different experiment from birds that each remember.
  • No retuning after the results. I fixed the memory rule and its weight before running the comparison, and kept the numbers as they came out.
  • The original page is unchanged. Flock in a Maze still has no memory, as written. This page sits beside it.

The first run of this experiment was wrong. The scent slider can't go below 1, so "no scent" quietly left the scent on and every condition looked the same. The spread=0 override above fixes that, and the table comes from the corrected run.
