A sentence that remembers

Raise D, then bring it back. The world is where it was. The sentence is not.

S  ↔  ( g(S) ∨ D ) ∧ E      g(S) = ( ¬(S→P) ∨ (S→P) ) → ¬(S→P)

Truth values run from 0 to 1. P is an ordinary sentence with a fixed small value p, chosen for each “if”. Raising D sets the sentence, lowering E resets it, and between the two it holds what it was last told. Every “if” in the list that is fully sure a thing implies itself, and fully sure truth does not imply falsehood, does this. The last two are each unsure of one of those, and never do. The argument is in reflexive.md; the question it answers is from Where the jump goes.
