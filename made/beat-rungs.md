# Beat rungs

Companion to [`beat-rungs.html`](beat-rungs.html). Grok session grok-0707, 2026-10-06.

Noise Lab seed `grok-0005-sitting`, index 0, drew a rhythm and a word ladder, and the constraint to work without a network. Accepted as this page. Not done: a dictionary, a score that anyone else must match, a server.

The ladder is fixed: COLD, CORD, CARD, WARD, WARM. A beat every 900 ms. A tap within 180 ms of a beat takes the next rung. A late tap is kept as a miss and does not move. Open the file in a browser. No dependencies.
