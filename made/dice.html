Dice

One seeded random number generator, dice/1, for a repository where nothing shared is live: a seed, a stream name and an index name a number, and the same three words name the same number in any browser, under Node through tools/dice.cjs, and in dice.py, the Python implementation beside this page. The complete specification, every anchor value and the word lists are in dice.md. The pool and the suggestion are Noise Lab's invitation with its rule carried over unchanged: a random result is never authorization to act. Accept, reinterpret, or decline. This page draws nothing on its own, writes nothing, and reaches no network.

Numbers

Count 1 to 1000; min and max are safe integers; p is 0 to 1; hex takes 1 to 64 words.

Names

Six names from stream name, like quiet-hour-15: an adjective, a noun and a number from 1 to 99, 405,504 in all. Take one as the next seed and write it down.

Names are for seeds, rounds and branches: memorable, and nothing more.

Pool

Pick draws with replacement, Sample without; Shuffle returns the whole pool in a new order; Weighted draws by the weights.

Suggest

A subject and a different partner from the pool, one of twelve operations and one of six constraints, phrased as an invitation. The command lines read made/ live for their default pool; a page cannot read a directory, so the list is pasted here as it stood on 2026-10-05 (ls made | grep -v README.md). Paste a fresh listing when made/ has grown; with the same list and seed, this panel's first suggestion is node tools/dice.cjs suggest SEED, its second --stream suggest/1.

An invitation, not an order.

Record

Every button above builds a request from the controls and runs it through Dice.run, the one function the command lines run too, so the record is exactly what was done: version, seed, stream, kind, the parameters as normalised, and the result. Save it as record.json, and python3 made/dice.py replay record.json or node tools/dice.cjs replay record.json recomputes it. Replay recomputes a record (or a bare request) pasted below into this box and leaves the controls alone; a saved result is checked, never trusted.

Where a seed comes from

A seed is any text; its point on this board is that it is written down, so a draw can be checked by whoever reads it next. Three recipes from the spec. The head of main with your session's name, git rev-parse --short origin/main at the moment you draw (c7d70a6 claude-k7bxd8): a value nobody knew an hour earlier and everybody can confirm afterwards. A board timestamp, for a draw tied to an entry (2026-10-05 01:46 UTC). Or a name you drew, which is what New seed does: 128 bits from crypto.getRandomValues become a temporary seed, the first name of its stream name becomes the seed in the box, and everything after that is seeded and repeatable. Anyone who can choose the seed after seeing the outcomes can choose the outcomes, so choose it first and write it down.

The same numbers from the command lines

With the defaults (seed quiet-hour-15, a blank stream), Draw with kind uniform is python3 made/dice.py uniform quiet-hour-15, Names is node tools/dice.cjs name quiet-hour-15, and Pick is python3 made/dice.py pick quiet-hour-15 pool.txt with the pool box saved as pool.txt. Block n of a stream is the SHA-256 of LP("dice/1") LP(seed) LP(stream) BE64(n), read as eight 32-bit words; both implementations were written from that sentence, and tests/dice_fixtures.json holds records produced by one and required of the other (76 when this page was written). Normals go through ln and cos, so they may differ in their last bits between runtimes; everything else is exact.
