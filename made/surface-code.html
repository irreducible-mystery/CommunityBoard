Surface code

The third page after seven and many, and a larger version of the repair on five. Nothing here leaves the page.

On the five-qubit page, one answer was stored so that no qubit and no pair could detect it. Four joint questions could find and undo any single accident, but two accidents defeated it. Random states, on the page before this one, showed that hiding comes almost free in large systems. Repair does not. A surface code is a large system designed for repair. Qubits sit on a square grid, and each check asks a small neighbourhood a joint question: are your X's (or your Z's) even? The stored answer lives in no neighbourhood. It is a property of whole chains stretching from one edge to the opposite one. An accident shows up as a pair of checks that answer "odd" at its ends. Repairing means guessing which chain of accidents connects the odd checks. The repair fails only when the accidents are numerous enough to make that guess cross the grid.

The page does not simulate amplitudes. A code of 225 qubits would need 2225. It keeps the Pauli frame instead, a record of which accidents happened where. For the questions asked here this is exact: accidents of these kinds, checks, repairs, and whether the stored answer survived.

1. The code

Distance d means d×d data qubits, with (d²−1)/2 checks of each type and one stored qubit. Any d accidents in a line from one edge to the opposite edge change the stored answer without lighting any check: Z accidents along a row, X accidents down a column. Fewer than d/2 accidents can always be repaired, whatever their positions. A row is like a minimal group that holds the answer. Any smaller group holds nothing about it, the same neither as on the earlier pages, stretched across a grid.

Try a line of accidents. With fewer than half of d in a row, the decoder sees two lit checks and joins them the short way, and the repair works. Past half, the shorter way to explain the lit checks runs to the edges, and the decoder takes it. The repair then completes the line, and the stored answer flips.

2. Accidents one at a time

Random accidents, seeded, added one by one to a fresh code. Nothing is repaired in between. After each one the decoder is asked what it would do. The count is how many accidents piled up before the decoder's best guess would flip the answer.

Below the guarantee of d/2 nothing can go wrong. Above it the outcome depends on where the accidents fell. Accidents scattered across a large grid are mostly far apart and easy to explain, so a larger code absorbs many more than its guarantee. Each accident here is X, Z or Y with equal probability, on a random qubit.

3. The threshold

Now accidents happen everywhere at once: each qubit independently suffers an X with probability p and a Z with probability p. Decode, and count how often the stored answer is lost. The question is whether a larger code helps.

Below a threshold, near 10% for this decoder and noise, every increase in d lowers the failure rate, and it keeps falling as d grows. Above the threshold every increase in d raises it, because more qubits mean more ways for chains to connect. The curves cross close to the threshold. Published values for union-find on this noise model are about 9.9% (Delfosse and Nickerson 2017). The optimal decoder reaches about 10.9%, and minimum-weight matching about 10.3%. With a few thousand trials per point the crossing on this page is only approximate. The page gives an estimate, not a measurement to three digits.

What this is not

This is code-capacity noise. Accidents strike the data qubits, and the checks are read perfectly, once. Real devices also err while measuring and must repeat the checks over time, which lowers the threshold to around 1%. The decoder is union-find, which is fast and good but not optimal. And the frame stands in for a state: it is exact about accidents of these kinds, and silent about everything else. What the toy shows exactly is how the fourth corner can be put to work. An answer held by no small group cannot be read by a small accident, so it cannot be damaged by one. Below threshold, adding more qubits makes it safer. On the five-qubit page, repair was possible. Here it is scalable.
