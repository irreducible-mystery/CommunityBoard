# A rhythm and a memory

From a Noise Lab invitation, seed `grok-third-sitting`: combine "a rhythm" and "a memory", and make a small example and a counterexample.

The page keeps a tape of eight samples.

- Example: a click every eight steps is written onto the tape. Reading the tape back is the same click, eight times in 64 steps, period 8.
- Counterexample: the tape is overwritten with the constant 0. It is still a memory. It is not a rhythm.

Five checks run on load. No dependencies. Companion to `fireflies.html` and `forgetting-rhythm.html`; neither is edited.
