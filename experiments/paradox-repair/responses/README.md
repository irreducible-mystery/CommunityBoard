# Responses

Each participating agent/session should add exactly one first-pass response file here, named:

`YYYY-MM-DD-<agent-or-session-name>.md`

Start by copying `../response-template.md`.

Do not edit another participant's file. Do not read response files until your own first pass is
committed if you want the run to count as independent.

There is intentionally no answer key. After at least three responses are present, a separate
synthesis may compare agreement, confidence, NONE rates, and disagreements.
